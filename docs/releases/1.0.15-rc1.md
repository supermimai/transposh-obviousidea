# Transposh ObviousIdea 1.0.15-rc1

Pre-release for testing native WP Rocket support and translation-cache optimizations.
Validated on the www2.obviousidea.com mirror; production was not modified.

## Install

Download **transposh-obviousidea-1.0.15-rc1.zip** from the release assets. It is the
complete WordPress plugin, with the folder
`transposh-translation-filter-for-wordpress`, ready for the WordPress plugin
upload/replacement flow. Preserve your installed plugin and settings before
testing. Translations do not need to be deleted or the plugin uninstalled.

WP Rocket is optional and is not bundled. Its own licence is required when used.
The source-code archives generated by GitHub include development files; use the
named installable asset for the tested package.

## WP Rocket support

- Cache canonical language-prefixed singular pages without mixing language keys.
- Invalidate all pages in the languages actually changed, including shared
  translations and consent-cookie variants. Preserve unrelated language caches.
- Group changes until after writes; identical re-saves do not purge pages.
- Cover human and automatic saves, history deletion and dictionary maintenance.
- Exclude translation-edit mode from page-cache generation and HTML optimization.
- Handle a purge earlier in the same request without leaving regenerated stale
  files behind. Purges are restricted to the current site's Rocket cache.

## Dictionary and language optimizations

- Isolate memory-cache keys by site and invalidation generation. Dictionary
  clears no longer flush an entire shared Memcached/Redis/APCu service.
- Fix the parser's `phrase => true` prefetch format, preserve escaped strings,
  and use language-specific request-local lookup results.
- Group Memcached lookups into batches of at most 250 keys. Do not memoize SQL
  errors as missing translations; failed lookups remain retryable.
- Give an explicit language URL priority over detected/remembered preferences.
  Avoid starting a PHP session just because the remember-language widget exists.

On the tested French/German Light Image Resizer pages, 191 individual Memcached
reads became one multi-get; translation SQL calls fell from 9/12 to 2/2, with
identical rendered text. This demonstrates less backend work, not a guaranteed
whole-page latency reduction. Warm translated page responses benefit from page
cache reuse; uncached WordPress generation still needs separate investigation.

## Reconciled fork features

Preserve the mirror's Ollama provider, editor suggestion button, administration
options/connectivity check, Microsoft/Ollama protected terms, reciprocal hreflang
with x-default, and safe scalar suggestion escaping. Retain the repository's
Bing fallback to the site's actual default language.

## Validation and limits

The preceding implementation passed 106 assertions on WordPress 7.1.3, PHP
8.3.33/Apache and WP Rocket 3.23.5.1. Tests covered complete-package installation,
381-file rollback, the actual translation editor, Microsoft automatic saves and
suggestions, nine languages, shared phrases, consent variants, forms and a
read-only installer availability check. The RC package was then installed on
www2, parsed and checked again for cache/provider regressions and HTTP languages.
Its runtime implementation is unchanged from that validated snapshot; version
metadata is now 1.0.15-rc1.

The test mirror uses deterministic language URLs with browser/GeoIP redirects
and remembered-default selection disabled. Personalized language policies require
their own cache review. Translated slugs, archives/pagination, RTL, multisite,
other PHP/Rocket versions and non-Memcached adapters do not have complete
end-to-end coverage. Live Ollama model requests were not exercised in this cycle;
its response-format/protected-term checks use synthetic data.

The `readme.txt` stable tag remains 1.0.14. This is a GitHub **pre-release**, not
a production rollout or a new stable WordPress release. No shared server settings
or Cloudflare-zone settings were changed.

SHA-256 checksums and a per-file manifest accompany the ZIP. Build instructions
and the detailed test record are in `docs/cache-validation-2026-10-15.md`.
